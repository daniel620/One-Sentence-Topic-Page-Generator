OpenAI Releases GPT-5.5 Instant as New Default ChatGPT Model

The successor to GPT-5.3 Instant brings a massive context window, updated knowledge cutoff, and new safeguards.

On May 5, 2026, OpenAI released GPT-5.5 Instant, replacing GPT-5.3 Instant as the default model powering ChatGPT. The new model features a 1,050,000-token context window and knowledge cutoff of December 1, 2025. OpenAI deployed its strongest set of safeguards to date, incorporating feedback from nearly 200 early-access partners before the public launch.
